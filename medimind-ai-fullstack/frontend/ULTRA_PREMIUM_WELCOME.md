## 💡 How to Customize

### Change Colors:
Edit the gradient strings in the data objects:
```javascript
gradient: "from-teal-500 via-cyan-500 to-sky-500"
```

### Add More FAQs:
Add to the `faqs` array in the data section:
```javascript
{
  category: "New Category",
  icon: YourIcon,
  gradient: "from-color-500 to-color-600",
  questions: [...]
}
```

### Adjust Animations:
Modify the animation variants at the top:
```javascript
const fadeUp = {
  hidden: { opacity: 0, y: 60 },
  show: { opacity: 1, y: 0 }
};
```
